# 🛠️ Classified Ads API & Admin Panel

![Laravel](https://img.shields.io/badge/Laravel-11.x-FF2D20?logo=laravel)
![PHP](https://img.shields.io/badge/PHP-8.2+-777BB4?logo=php)

![License](https://img.shields.io/badge/License-MIT-blue)

A RESTful API backend and administrative management dashboard for a classified advertisements mobile platform. Built with **Laravel** and **PostgreSQL**, it handles core business logic, user authentication, listing management, and localized data delivery.

---

## ✨ Key Features

- **⚡ RESTful API Architecture:** Clean JSON endpoints for mobile app integration.
- **📊 Admin Dashboard:** Content management system for listings, categories, and application settings.
- **🐘 Database Integration:** Structured schema optimized for scalable queries using PostgreSQL.
- **🌐 Localization:** Native support for multi-language configurations including Arabic (RTL).
- **🔐 Session & Queue Systems:** Database-driven sessions and background job queue processing.

---

## 🛠️ Tech Stack

- **Framework:** Laravel
- **Language:** PHP 8.2+
- **Database:** PostgreSQL
- **Frontend Assets:** Vite
- **Architecture:** RESTful API & Admin Panel
